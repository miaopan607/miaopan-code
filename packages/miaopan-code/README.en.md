# miaopan-code runtime

Languages: [简体中文](README.md) · English

This package contains the miaopan-code CLI, TUI, and API server runtime.

Install dependencies and build it from the repository root:

```bash
bun install
bun --cwd packages/miaopan-code run build
```

See the root [English README](../../README.en.md) for installation, configuration,
and usage information. Development requirements are documented in the
[English contribution guide](../../CONTRIBUTING.en.md).
