# @miaopan-code/miaopan-code

语言版本：简体中文 · [English](README.en.md)

本包是 miaopan-code CLI、TUI 和 API Server 的运行时。开发环境请在仓库根目录安装依赖后执行：

```bash
bun install
bun --cwd packages/miaopan-code run build
```

更多安装、语言配置和使用说明请查看根目录的 [中文 README](../../README.md)；API 和开发细节请查看 [English README](README.en.md) 以及 [贡献指南](../../CONTRIBUTING.md)。
