从本地文件系统读取文件或目录。如果路径不存在，则返回错误。

使用方法：
- filePath 参数应为绝对路径。
- 默认情况下，此工具从文件开头返回最多 2000 行。
- offset 参数表示开始读取的行号（从 1 开始）。
- 要读取后续区段，请使用更大的 offset 再次调用此工具。
- 使用 grep 工具查找大型文件或包含长行的文件中的特定内容。
- 如果不确定正确的文件路径，请使用 glob 工具按 glob 模式查找文件名。
- 返回内容时，每行都会以行号作为前缀，格式为 `<line>: <content>`。例如，如果文件内容为 "foo\n"，你将收到 "1: foo\n"。对于目录，每个条目单独占一行（没有行号），子目录末尾带有 `/`。
- 任何超过 2000 个字符的行都会被截断。
- 当你知道需要读取多个文件时，并行调用此工具。
- 避免反复读取很小的区段（30 行一块）。如果需要更多上下文，请读取更大的窗口。
- 此工具可以读取图像文件和 PDF，并将其作为文件附件返回。
