# miaopan-code V2 API 概览

语言版本：简体中文 · [English API map](api.html)

V2 API 使用统一的 `/api` 路由，为简单客户端和多目录前端提供相同入口。路由按运行时上下文分为三类：

- **Server 作用域**：管理项目、工作区生命周期和认证账户；
- **Runtime 上下文**：从活动目录解析配置、Provider 能力、工具、文件和 VCS；
- **Session 固定**：会话条目路由从会话存储解析。

所有资源拥有一个规范路由。请求上下文决定非会话路由的目录，Session 路由则使用会话自身的位置。事件采用统一 envelope，前端 Store 通过事件同步状态。

可视化端点清单、上下文流程图和事件模型请打开 [英文 API map](api.html)。本文仅作中文导航，不翻译协议字段、端点名称或类型标识。
